# How To Ask This Guide

This Flint is a Guide about one subject. A person clones it, opens it with an agent, and asks questions.

How to ask:

1. Open an agent session in this Flint.
2. Ask one question at a time. Give the name of the thing that you ask about.
3. The agent reads the Mesh of this Flint and answers from it. It names the notes that it used.
4. If the Mesh has no answer, the agent says so. It does not guess.

How to keep the guide correct:

- Write one subject per note. Use short sentences.
- Put the date on a fact that can change.
- The visibility is `public`. Write nothing here that only one org may read.
