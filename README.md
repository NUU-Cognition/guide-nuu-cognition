# (Guide) NUU Cognition

You cloned a Guide. A Guide is a small, public Flint workspace that you open with an AI agent and ask questions of. This one is about NUU Cognition: the organisation, its idea of thinking technologies, and its tools: Flint, Shards, Mesh, NCM, Vessel, Surf, Parse, NUU Docs, OrbCode, and the NUU Network. It is a front door, not the full knowledge base. Every note is short and holds one subject. The notes link to each other, so you can start anywhere.

To use it, open a terminal in this folder and start a terminal agent such as Claude Code or Codex. Tell the agent to read `Mesh/(System) Flint Init.md` first. Then ask one question at a time, for example "What is a shard?" or "How do I install Flint?". The agent answers from the notes in `Mesh/Notes/` and names the notes that it used. When a question is outside the notes, the agent says so and points you to the public docs. You can also read the notes directly. Start with `Mesh/Notes/What NUU Cognition Is.md`, or open the folder in Obsidian and follow the links.

This Guide is public. It holds no secrets and no private facts. When you find an error, or a note that is out of date, change the note and keep it short, or open an issue where you got the clone. For the current install steps and the product sites, see `nuucognition.com` and `flint.nuucognition.com`.
